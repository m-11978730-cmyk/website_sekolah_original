Kos Tenaga & Jejak Karbon Teknologi

Memahami impak alam sekitar setiap klik, aliran, dan model AI

Mengapa Tenaga Teknologi Penting?

Dunia maya kelihatan "bersih" — tiada asap, tiada sampah kelihatan. Tetapi di sebalik skrin, ribuan pusat data (data centers) di seluruh dunia menganggarkan 1–1.5% elektrik global (IEA 2024), dan angka ini dijangka naik kepada 3–4% pada 2030 disebabkan AI generatif.

Setiap tindakan digital kita — carian, streaming, emel, AI chat — mempunyai kos tenaga dan jejak karbon. Halaman ini memecahkan data itu.

Di Mana Tenaga Itu Pergi?

🖥️ Komputasi (40–50%)

Prosesor (CPU/GPU/TPU) melaksanakan operasi matematik untuk AI, rendering, enkod video, carian.

❄️ Penyejukan (30–40%)

Pusat data memerlukan penyejukan intensif (AC, cecair, udara luaran) untuk mengelakkan server overheat.

🔌 Kuasa & Kerugian (10–15%)

Penukaran AC/DC, pengedaran kuasa dalam rack, kerugian haba, sistem backup (UPS, generator).

🏗️ Emas & Pembinaan (embedded)

Penghasilan server, kabel, bangunan, semikonduktor — "karbon terkandung" sebelum operasional.

AI Generatif: Penghabis Tenaga Baru

Fasa Latihan (Training)

  • Bertahun-tahun GPU beroperasi 24/7
  • GPT-3: ~1,287 MWh = 500+ t CO₂ (sepadan 112 kereta setahun)
  • GPT-4 / Llama-3-405B: jauh lebih tinggi (data tidak dimaklumkan penuh)

Fasa Inferens (Serving)

  • Setiap pertanyaan pengguna = operasi matrix besar
  • ChatGPT: ~10× tenaga carian Google
  • Imej AI (Midjourney/DALL-E): ~50–100× tenaga carian teks
  • Video AI (Sora/Veo): ratusan kali lebih

🔧 Teknik Penurunan Kos

  • Quantization INT4/INT8: 4–8× lebih sedikit memori & compute
  • Speculative Decoding: Model kecil draft → model besar verify, 2–3× laju
  • KV Cache Compression: Kurangkan memori context 50–75%
  • Continuous Batching / PagedAttention: GPU utilization 90%+
  • TensorRT-LLM / vLLM / SGLang: Framework inferens optimum

Apa Yang Boleh Kita Buat?

🌐 Pilih Penyedia Hijau

Google, Microsoft, Amazon komited 100% tenaga boleh diperbaharui. Sokong perkhidmatan yang teluskan data PUE (Power Usage Effectiveness) & pembelian RECs.

📉 Kurangkan Resolusi Apabila Tidak Perlu

Tonton 1080p, bukan 4K, untuk konten biasa. Hemat 60–70% tenaga streaming.

🤖 Guna AI Secara Bijak

Elak pertanyaan berulang/panjang tidak perlu. Gabungkan soalan. Guna model lebih kecil (quantized/local) untuk tugas ringan.

🗂️ Hapus Data Tidak Perlu

Fail cloud lama, emel spam, backup ganda — menyimpan data memerlukan tenaga berterusan (SSD/HDD + penyejukan).

🔧 Sokong Perisian Cekap

Kod yang dioptimumkan (algorithm lebih baik, less bloat) mengurangkan kitaran CPU. Pembangun: profile kod, elak loop tidak perlu.

♻️ Kitar Semula Peranti

E-waste mengandungi bahan toksik & nilai (emas, kobalt). Kitar semula mengurangkan permintaan penambangan baru.

Masa Depan: Menuju Komputasi Hijau

  • Pusat data tenaga nuklear/geothermal: Microsoft, Google, Amazon menandatani PPA nuklear modular kecil (SMR) untuk bekalan 24/7 bebas karbon.
  • Penyejukan cecair & rendaman: Mengurangkan tenaga penyejukan sehingga 90% berbanding udara.
  • Chip analog/neuromorphic: Komputasi AI dengan pecahan tenaga GPU biasa (contoh: IBM NorthPole, Mythic).
  • Model kecil & distillation: Model 1B–7B parameter yang di-distil dari model besar — 90% prestasi, 1% kos.
  • Komputasi tepi (edge): Proses di peranti pengguna (phone/laptop) = tiada tenaga pusat data + latensi rendah.
